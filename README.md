# Healthy-Posture
Healthy Posture - десктопное приложение, способное автоматически определять нарушения в сидячей позе человека с помощью модели компьютерного зрения и своевременно оповещать его об этом с помощью уведомлений.

# Основной функционал:
1) Система уведомлений двух типов – оповещение о неровности текущей позы и о необходимости сделать перерыв;
2) Настройка уведомлений, их звука, частоты и наличия в целом;
3) Панель со статистикой, состоящей из четырёх графиков, удобно обновляющихся и отображающих процентное соотношение типов осанки (верная или неверна),
   дни пользования приложением, а также вывод графической аналитики сидячей позы на каждый день в течение текущего месяца;
4) Система сохранения данных для отображения статистики на каждый день и сохранения условий настроек;
5) Страница рекомендаций для профилактики здоровья осанки.

# Как запустить программу:
1) Склонировать репозиторий;
2) Создать окружение:
   `python -m venv venv`
   `venv\Scripts\activate`
3) Установить зависимости:
   `pip install -r requirements.txt`
5) Запустить файл main.py:
   `python main.py`.
